# File Sorter — универсальный сортировщик файлов

Кроссплатформенный сортировщик файлов на Python (3.10+): перемещает файлы в выбранной папке по правилам «расширение → папка». Только стандартная библиотека, ничего устанавливать не нужно.

## Возможности

- Правила сортировки в `rules.json` (создаётся автоматически из шаблона при первом запуске);
- Интерактивный диалог: показ правил, добавление/удаление правил, выбор папок;
- Показ плана («будет перемещено N файлов») и подтверждение перед перемещением;
- Конфликты имён решаются без перезаписи: `имя (1).расширение`;
- Журнал операций `log.txt` (что, куда, когда);
- Откат последней сортировки (`history.json`);
- Режим наблюдения: предлагает сразу отсортировать уже лежащие файлы, новые сортируются автоматически (остановка — Ctrl+C);
- Профили правил `rules-*.json` (выбор при старте, если есть).

## Запуск

```bash
python main.py
```
или на macos / linux
```bash
python3 main.py
```

Меню: `1` — правила, `2` — сортировать папку, `3` — наблюдать за папкой, `4` — откатить последнюю сортировку, `5` — очистить лог/историю, `0` — выход.

На вопрос «Папки для сортировки» введите пути через запятую или нажмите Enter — будет использована папка по умолчанию (`~/Downloads`, настраивается в `rules.json`).

## Настройка правил

Пункт меню `1` открывает редактор правил (выход — Enter):

- **добавить** — название, расширения через запятую, папка назначения. Путь проверяется: запрещены `..` (выход за пределы папки-источника), символы `< > " | ? *`, двоеточия (кроме `C:` в начале на Windows), части пути, заканчивающиеся точкой или пробелом, опечатки вида `~Documents` (нужно `~/Documents`). Также отклоняются абсолютные пути первого уровня от корня (`/Documents`, `C:\Documents`) — это read-only системные папки; домашние папки всегда пишутся через `~` (`~/Documents`) или относительным именем (`Documents` — создастся внутри папки-источника). Движок дополнительно отказывается перемещать файлы в корневой путь, даже если правила испорчены вручную;
- **удалить** — по номеру из списка, вводить название не нужно;
- **удалить ВСЕ** — очистить список правил (с подтверждением);
- **загрузить набор по умолчанию** — вернуть встроенный шаблон. Наборы свои для каждой ОС (при загрузке спрашивается: текущая / macOS / Windows / Linux). Цели указывают в существующие системные папки пользователя (macOS: `~/Documents`, `~/Pictures`, `~/Music`, `~/Movies`; Windows и Linux: `~/Documents`, `~/Pictures`, `~/Music`, `~/Videos`), поэтому при первом запуске новые папки не создаются. Папки «Archives» и «Code» — исключение: их в системе нет, они создаются внутри папки-источника. Шаблон хранится внутри программы, поэтому доступен всегда, даже если `rules.json` повреждён или удалён.

При старте программа проверяет пути: если какой-то целевой папки (или папки по умолчанию) не существует, печатается предупреждение — значит, при сортировке она будет создана.

Файл `rules.json` (создаётся автоматически при первом запуске):

```json
{
  "default_source": "~/Downloads",
  "rules": [
    {"name": "Documents", "extensions": [".pdf", ".docx"], "target": "Documents"}
  ]
}
```

- `extensions` — расширения с точкой (регистр не важен);
- `target` — папка назначения: относительная (создаётся внутри папки-источника) или абсолютная.

Свои наборы правил сохраняйте как `rules-работа.json`, `rules-учёба.json` рядом с `rules.json` — программа предложит выбрать профиль при старте.

## Откат последней сортировки

Каждая сессия сортировки записывается в `history.json`. Пункт меню `4` возвращает все файлы последней сессии на исходные места. Если на старом месте уже есть файл с таким именем — он не перезаписывается, возвращённый файл сохраняется как `имя (1).расширение`. Файлы, удалённые или перемещённые вручную, пропускаются с предупреждением.

## Журнал и история: ротация и очистка

Оба файла обслуживаются автоматически, вручную ничего удалять не нужно:

- `history.json` — хранит **последние 20 сессий** сортировки (старые вытесняются при записи). Откату нужна только последняя сессия, поэтому для пользователя ничего не меняется;
- `log.txt` — при превышении **1000 строк** обрезается до последних 500 (свежие записи всегда на месте).

Ручная очистка — пункт меню `5`: показывает текущие размеры и позволяет удалить log.txt, history.json или оба. После очистки истории откат будет недоступен, пока не пройдёт новая сортировка. Лимиты задаются константами `MAX_SESSIONS` в `sorter/history.py` и `MAX_LINES`/`KEEP_LINES` в `sorter/log.py`.

## Если файлы не сортируются (macOS)

Признак: программа работает, `rules.json` создаётся, но «файлов для сортировки не найдено», режим наблюдения молчит. Это почти всегда запрет доступа к папке: macOS защищает «Загрузки» и «Документы» от программ, и сканер видит папку пустой.

Решение: **Системные настройки → Конфиденциальность и безопасность → Файлы и папки** → найдите Terminal (или iTerm/IDE, откуда запускаете) → включите доступ к «Загрузки». Если пункта нет — включите **Полный доступ к диску**. После этого запустите сортировщик заново — при проблеме доступа программа теперь сама печатает подсказку «Проблемы доступа».

Также помните: режим наблюдения сортирует **новые** файлы; файлы, лежавшие в папке до запуска, он предложит разобрать сразу при старте.
